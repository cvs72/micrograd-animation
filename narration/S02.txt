Example A: the lecture's own function, d = a times b plus c.
Three inputs feed one output. Which input matters, and which way?
Each box is a Value. Times gives e = a*b, then plus c gives d.
A partial derivative: nudge ONE input and hold the others still.
b is negative, so a bigger a adds less. Does d rise or fall?
Nudge a by h = 0.0001 and watch the change travel along the arrows to d.
Now b. Since a is positive, a bigger b pushes d up. The slope is 2.
Last, c. What slope do you expect? It is simply added to the product.
c just adds on, so d rises exactly as c does: the slope is 1.
Three slopes: -3, 2 and 1. The slope for a is b; the slope for b is a.
The engine's backward pass writes these same slopes into grad.
Example B: what if we change the inputs? Watch the slopes recompute.
Morph to a = -1, b = 4, c = 0.5: d becomes -3.5 and the bars recompute.
The slope for a is the OTHER input b, and the slope for b is a: they swap.
Now set b to zero. What happens to the slope for a?
The slope for a is exactly 0: a times zero is zero, whatever a is.
Set a to zero as well: both slopes are 0, a flat point; only c matters.
All four cases side by side: each slope is just the other factor.
Expert corner: with two inputs, d = a times b is a surface. Here a saddle.
Each point of the floor is a pair (a, b); the height above it is d.
Contour lines on the floor join points that have the same d.
Our point (2, -3) sits at height 4. Which way is uphill?
The gradient (b, a) = (-3, 2) points straight uphill, across the contours.
The tangent plane touches the surface here: slope -3 along a, 2 along b.
A ball rolling against the gradient slides downhill, and d keeps falling.
The gradient is the vector of all the slopes: a compass pointing uphill.
