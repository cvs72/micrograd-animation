# S02 - Chapter 2: What if there is more than one input?

Summary: with several inputs, the slope of the output with respect to each input (a partial derivative) is found by nudging one input at a time, and the vector of all slopes is the gradient.

## Example A - the lecture's own numbers
- The notebook's d = a*b + c with a = 2, b = -3, c = 10 is drawn as Value boxes a, b, c, e = a*b and d, with a teal forward pulse filling in e = -6 and d = 4.
- Predict-then-reveal: b is negative, so a bigger a adds less; d must go down. Nudging a by h = 0.0001 slides a ghost copy of the number up and the change travels along the arrows: d falls from 4 to 3.9997.
- The working (2.0001 * (-3) + 10 - 4) / 0.0001 = -3 is shown with real numbers; bars grow from a zero line for the slopes -3 (a), 2 (b) and 1 (c); c is predicted first.
- The engine's backward pass then writes the same three slopes into grad.

## Example B - what if?
- The three inputs morph live (ValueTracker) to a = -1, b = 4, c = 0.5: d = -3.5, slopes 4, -1, 1; the slope for a equals b and the slope for b equals a (the two numbers swap).
- b is morphed to 0: the slope for a becomes exactly 0 (predicted first). Then a is morphed to 0: both slopes are 0, a flat point; only c matters.
- A table collects all four cases row by row.

## Expert corner - the gradient in 3D
- The surface d = a*b + 10 over a and b in [-4, 4] is a saddle, drawn on labelled 3D axes with a slowly orbiting camera and contour lines on the floor.
- At the marker (2, -3) the tangent plane has slope -3 along a and 2 along b; the gradient (b, a) = (-3, 2) is an arrow on the floor pointing uphill, across the contours.
- A ball rolling against the gradient slides downhill (d falls from 4 to about -1.1).

## Formulas
- slope for input x = (d(x + h) - d) / h
- d = a*b + c: the slope for a is b, the slope for b is a, the slope for c is 1
- gradient = (partial d / partial a, partial d / partial b) = (b, a)

## Three key takeaways
- A partial derivative nudges ONE input and holds the others fixed.
- For a product, the slope for one factor is the OTHER factor; for a sum, the slope is 1.
- The gradient collects all slopes in one vector and points straight uphill, so minus the gradient points downhill.

## Glossary
- Partial derivative: the slope of the output when only one input moves.
- Gradient: the vector of all partial derivatives; it points in the direction of steepest increase.
- Contour line: a curve of points with the same output value.
- Tangent plane: the flat sheet that touches a surface at one point and has the same slopes there.

## Two common mistakes
- Nudging several inputs at once and then dividing: you can no longer tell which input caused the change.
- Thinking that the gradient points downhill: it points uphill; training moves against it.
