# S04 Backward pass by hand (Scene04BackwardManual)

Summary: starting from the finished forward pass of L = (a*b + c) * f, we fill in every grad by hand, node by node, using local derivatives and the chain rule, then check the numbers and take one optimisation step.

## Example A (the lecture's own graph)
- a=2, b=-3, c=10, f=-2 give e=-6, d=4, L=-8; every grad starts at 0.
- Base case L.grad = 1, then the times node swaps in the other input: d.grad = f = -2 and f.grad = d = 4.
- The car, bicycle and walking man bars show that rates multiply along a path: 2 * 4 = 8.
- The plus node is a router: c.grad = e.grad = -2. Then a.grad = (-2) * 1 * (-3) = 6 and b.grad = (-2) * 2 = -4.
- Numerical check: nudging a by h = 0.0001 moves L by about 6 * h.
- One step: every leaf moves 0.01 along its gradient and L rises from -8 to -7.2865.

## Example B (what if)
- a=-2, b=5, c=-3, f=0.5 give L=-6.5 and grads 2.5, -1, 0.5, -13; the numbers morph live and particles flow again.
- f=0 gives L=0 with a.grad = b.grad = c.grad = 0 and f.grad = 4: multiplying by zero blocks everything upstream.

## Expert corner
- Gradient checking: a table compares backprop with central finite differences for every leaf; errors are about 1e-9 or smaller.
- Reverse mode against forward mode: with 1 output and 1000 inputs one backward pass gives all 1000 gradients; forward mode needs 1000 passes.

## Formulas used
- dL/dd = f, dL/df = d (times node).
- dL/dc = dL/dd * dd/dc (plus node, local derivative 1).
- dL/da = dL/dd * dd/de * de/da.
- x <- x + 0.01 * dL/dx (one optimisation step).

## Key takeaways
- A local derivative only needs a node's own inputs; the chain rule multiplies them along the path back to L.
- Plus routes the gradient unchanged; times hands each input the other input's value.
- Reverse mode gives every gradient in one pass, which is why neural networks use it.

## Glossary
- Local derivative: how a node's output reacts to one of its own inputs.
- Chain rule: multiply the local derivatives along a path.
- Gradient check: compare backprop with finite differences.
- Reverse mode: one backward pass from one output to all inputs.

## Common mistakes
- Forgetting to multiply by the gradient that already arrived (using only the local derivative).
- Thinking a zero gradient means a bug: here it is correct because the output was multiplied by zero.
