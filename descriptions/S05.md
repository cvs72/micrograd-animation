# S05 One neuron with tanh (Scene05NeuronTanh)

Summary: a neuron multiplies inputs by weights, adds them with a bias, squashes the sum with tanh, and backpropagation through its Value graph shows which weights matter and when learning stalls.

## Example A (the lecture's own neuron)
- A cartoon of a brain cell: inputs, synapse weights that multiply, a cell body that sums and adds a bias, then a squashing activation function.
- The tanh curve on real axes with a sliding dot: with bias 8 the sum is n = 2 and tanh gives 0.9640, in the flat tail.
- The Value graph x1*w1, x2*w2, their sum, plus b, then tanh; the bias morphs from 8 to 6.8814, so n = 0.8814 and o = 0.7071.
- Backward pass node by node: o.grad = 1, n.grad = 1 - o^2 = 0.5, plus nodes route 0.5, then x1.grad = -1.5, w1.grad = 1.0, x2.grad = 0.5, w2.grad = 0.0 (x2 is 0).

## Example B (what if)
- Bias 0: n = -6, o = -0.99999, 1 - o^2 is about 0.000025, so every gradient is almost 0 (x1.grad about -0.0001): the neuron is saturated.
- x2 = 1: o = 0.9546, w2.grad = 0.0887 (x2 times 1 - o^2), x1.grad = -0.2661, w1.grad = 0.1774; the dot slides along the curve and the bars grow or shrink live.

## Expert corner
- tanh and its slope 1 - tanh(n)^2 plotted together; the red bands where the slope is under 0.1 are the vanishing-gradient regions; at n = 4 the slope is 0.0013.
- A healthy ReLU neuron (w = 1, x = 2: output 2, grads 1 and 2) next to a dead one (w = -1, x = 2: output 0, both grads exactly 0.0).
- Large weights or inputs push the sum into the flat tails, so the scale of weights matters.

## Formulas used
- n = x1*w1 + x2*w2 + b and o = tanh(n).
- n.grad = (1 - o^2) * o.grad.
- Plus passes the gradient to both inputs; times swaps in the other input: w2.grad = x2 * x2w2.grad, x1.grad = w1 * x1w1.grad.
- ReLU: r = max(0, w * x).

## Key takeaways
- A neuron is just multiply, add, add a bias, squash; each piece is a node with a simple local derivative.
- tanh's local derivative is 1 - o^2, which is biggest at 0 and almost 0 in the tails.
- A zero input makes its weight's gradient zero, and a dead ReLU blocks all gradient.

## Glossary
- Activation function: the squashing step after the sum (tanh or ReLU).
- tanh: a curve that maps any number into -1 to 1.
- Bias: a number added to the sum that shifts how eager the neuron is.
- Saturation: the sum sits in a flat tail of tanh, so gradients are almost 0.
- ReLU: max(0, x), keeps positives and zeroes negatives.

## Common mistakes
- Reading a zero gradient as a bug when the input it multiplies is zero.
- Letting weights and inputs grow so large that tanh saturates and learning stalls.
