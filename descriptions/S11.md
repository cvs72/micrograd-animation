# S11: Loss and gradient descent

Summary: a 41-knob network is trained on four examples by measuring one loss number and nudging every weight against its gradient, over and over.

## What happens
- Example A: the lecture's four examples, MLP(3, [4, 4, 1]) with seed 1, the guesses next to the targets, the loss 6.2443, one update with real numbers, then 30 steps at learning rate 0.05 (loss 0.0346) and the weights changing thickness.
- Example B: what if the learning rate changes? Five runs from the same start race on one plot (0.001, 0.01, 0.05, 0.3, 1.0), then the predictions of 0.3 morph into those of 1.0, which is stuck near loss 8.
- Expert corner: forgetting to zero gradients, 41 knobs against 4 examples (overfitting), the loss as a design choice (squared against absolute), and what real training adds.

## Formulas used
- Loss: L = sum of (prediction - target)^2 over the four examples.
- Update: p <- p - lr * g, with g the gradient of the loss with respect to p.
- Squared-error slope: d/de e^2 = 2e. Tanh slope: 1 - o^2.
- Kept gradient without zeroing: g_kept = g_old + g_new.

## Key takeaways
- The loss turns "how wrong is the network" into one number; the gradient says which way every knob lowers it.
- Gradient descent is forward, backward, update, repeat; the learning rate sets the step.
- Too small is slow, too large overshoots and can saturate tanh so the gradients vanish and training stops.

## Glossary
- Loss: one number measuring how wrong the network is; low is good.
- Learning rate: the size of each step against the gradient.
- Gradient descent: repeating forward, backward and update to lower the loss.
- Overfitting: doing well on the training examples but not on new ones.
- Zero grad: setting every gradient to 0 before backward, because backward adds.
- Mini-batch, cross-entropy, L2 regularisation, learning-rate decay: ingredients of real training.

## Common mistakes
- Forgetting to zero the gradients: gradients pile up, the steps get too big, and in tiny problems the loss still falls so nobody notices.
- Picking a learning rate that is too big: the loss jumps, tanh saturates and the network gets stuck.
