# S10: Building a neural network from Values

Summary: a neuron, a layer and an MLP are small Python classes built from Value objects; MLP(3, [4, 4, 1]) holds 41 parameters.

## What happens
- Example A: the lecture's Neuron, Layer and MLP code, then MLP(3, [4, 4, 1]) runs on x = [2, 3, -1] with the signal pulsing layer by layer (output 0.6457 with seed 1).
- Example A: the parameter count is built up as 16 + 20 + 5 = 41 with an animated counter, after a predict-then-reveal question.
- Example B: the architecture changes live to MLP(3, [8, 8, 1]) with 113 parameters and MLP(2, [4, 1]) with 17, and the counter follows.
- Example B: three random seeds give three different outputs (0.6457, -0.1197, 0.9191) for the same input.
- Expert corner: with every weight 0.5 and every bias 0, the neurons of a layer get identical gradients, so they stay twins; random initial weights break the tie.
- Expert corner: the general formula P = sum of (inputs + 1) times neurons per layer, drawn as a stacked bar 16 / 20 / 5.

## Formulas used
- act = w1*x1 + w2*x2 + w3*x3 + b, then out = tanh(act)
- P = sum over layers of (n_in + 1) * n_out
- (3+1)*4 + (4+1)*4 + (4+1)*1 = 16 + 20 + 5 = 41
- (3+1)*8 + (8+1)*8 + (8+1)*1 = 32 + 72 + 9 = 113
- (2+1)*4 + (4+1)*1 = 12 + 5 = 17

## Key takeaways
- A neuron owns one weight per input plus one bias; a layer is a list of neurons; an MLP calls layers in sequence.
- The number of parameters grows quickly with layer width, because each layer connects to the next.
- Weights must start random, otherwise neurons in a layer get the same gradient forever.

## Glossary
- Neuron: weights times inputs, plus a bias, then tanh.
- Layer: several neurons reading the same inputs.
- MLP: a multi-layer perceptron, layers called one after another.
- Parameter: a weight or a bias, one knob that training may turn.
- Symmetry breaking: using random initial weights so equal neurons become different.

## Common mistakes
- Forgetting the bias when counting parameters: each neuron has inputs + 1 numbers.
- Initialising all weights to the same value, so extra neurons add nothing.
