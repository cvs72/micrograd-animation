# S08: more operations and the level of abstraction

Summary: to build real expressions the Value class needs plain-number support, a few more operations and the insight that an operation can be as big or as small as we like, as long as its local derivative is right.

## What happens in each act
- Example A: a + 1 fails because a plain number has no data attribute, so numbers are wrapped in a Value. 2 * a fails because Python asks int first, then falls back to a.__rmul__, which swaps the operands. Then a table of recipes: exp, power, division, subtraction and negation, with real gradients from the engine.
- Example A (continued): the neuron's fused tanh (2 nodes around n) is rebuilt from six small nodes (times 2, exp, minus 1, plus 1, power -1, times); the gradient flows back node by node and gives the same 0.7071 and the same gradients -1.5, 1, 0.5, 0.
- Example B: sigmoid built from exp, plus, times and power; at x = 1 it gives 0.7311 and slope 0.1966 = s(1-s); the sigmoid curve is morphed into 2 sigma(2x) - 1, which lands exactly on tanh.
- Expert corner: the rebuilt tanh needs e^(2x), which overflows for x = 400 (OverflowError: math range error, beyond 2x = 709.78); the stable rewrite uses e^(-2x) and returns exactly 1; fusing operations needs fewer nodes (10 instead of 18 in the neuron graph).

## Formulas used
- d/dx e^x = e^x, grad = e^2 = 7.3891
- d/dx x^k = k x^(k-1), for x = 3 and k = 2: 2 * 3^1 = 6
- a / b = a * b^(-1): 1/3 = 0.3333 and -6/9 = -0.6667
- a - b = a + (-b) and -a = a * (-1)
- tanh(x) = (e^(2x) - 1) / (e^(2x) + 1)
- sigma(x) = 1 / (1 + e^(-x)), sigma'(x) = s (1 - s) = 0.7311 * (1 - 0.7311) = 0.1966
- tanh(x) = 2 sigma(2x) - 1
- stable tanh for x >= 0: (1 - e^(-2x)) / (1 + e^(-2x)) = (1 - 0) / (1 + 0) = 1

## Three key takeaways
- Wrapping plain numbers and defining __rmul__ lets ordinary Python expressions build the graph.
- Any operation works if it provides a forward value and a correct local derivative; five big or fifteen tiny nodes give the same gradients.
- Mathematically equal formulas can behave differently on a computer: the rewritten one avoids overflow.

## Glossary
- Operator overloading: defining what + and * mean for our own class.
- __rmul__: the method Python calls when the left operand (an int) cannot multiply our Value.
- Power rule: the derivative of x^k is k x^(k-1).
- Sigmoid: a squashing function from 0 to 1, 1 / (1 + e^(-x)).
- Overflow: a result too big for a float, here raising OverflowError.
- Fusing: writing several steps as one operation with one hand-written derivative.

## Two common mistakes
- Thinking a node must be an elementary operation: a composite such as tanh is fine if its local derivative is right.
- Assuming that equal formulas are equally safe: e^(2x) overflows at x = 400 while the rewritten form does not.
