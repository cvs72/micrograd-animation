# S06: automating the backward pass

Summary: the backward pass must visit every node only after everything that depends on it has pushed its gradient in, and a depth-first topological sort finds that order automatically.

## What happens in each act
- Example A: the ten-node neuron of chapter 5 (x1=2, x2=0, w1=-3, w2=1, b=6.8814, o=0.7071) is differentiated by hand in a good order, then the per-operation closures (plus, times, tanh) are shown, then a depth-first walk drops nodes into a list in the order they finish, the list is flipped, and backward runs along it with the matching closure line shown; a wrong order pushes a zero into x1 and w1.
- Example B: a diamond a=2, b=a*2, c=a+3, d=b*c (b=4, c=5, d=20) gets two different valid orders that both give a.grad=14, and an invalid order that gives 10.
- Expert corner: nodes plus edges grow in a straight line with chain length (4n+1), a recursive sort fails with a RecursionError on a chain of 2000 additions, and a new iterative function with an explicit stack sorts all 4001 nodes.

## Formulas used
- n.grad = (1 - o^2) * o.grad = 0.5 and x1.grad = w1 * 0.5 = -1.5
- dd/da = c * 2 + b * 1 = 5 * 2 + 4 * 1 = 14
- N + E = (2n + 1) + 2n = 4n + 1, so 1201 for n = 300

## Three key takeaways
- A node's backward may only run after all nodes that use it have run theirs.
- A topological order puts every node after its children; reversing it gives the backward order, and many orders are valid.
- The sort costs one visit per node, but recursion depth is limited, so deep graphs need an explicit stack.

## Glossary
- Topological order: a list where every node comes after all of its children.
- Closure: a small function that remembers the node it was made for (the _backward rule).
- Depth-first walk: follow children as far as possible before backing up.
- RecursionError: Python's protection against calls nested too deeply (default limit 1000).

## Two common mistakes
- Running a node's _backward before its parent has deposited a gradient: its children receive a wrong zero.
- Believing there is only one correct order: any order that respects the children-first rule gives identical gradients.
