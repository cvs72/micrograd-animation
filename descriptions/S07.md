# S07: why gradients are added (+=) and not assigned (=)

Summary: when one node feeds the output through several paths, each path deposits its own share of the gradient, so the backward step must add (+=); assigning (=) silently keeps only the last share.

## What happens in each act
- Example A: b = a + a with a = 3 gives b = 6; the buggy "=" version ends with a.grad = 1 while the real "+=" version gives 2. Then the notebook's second case, a = -2, b = 3, d = a*b, e = a+b, f = d*e (f = -6): buggy a.grad = -6 and b.grad = -6, real -3 and -8, shown on a split screen.
- Example B: z = a + a + a gives 3 against the buggy 1, y = x*x with x = 2 gives 4 against 2, and a nudge of 0.001 moves the output by 0.002, 0.003 and 0.004, matching the real gradient only.
- Expert corner: the gradient of a is the sum over paths (e*b + d*1 = 3 + (-6) = -3, and for b: e*a + d*1 = -2 + (-6) = -8); without zeroing, grads accumulate across steps (6, 12, 18); accumulating four small batches (-1, 0, 3, 8) gives 10 on purpose.

## Formulas used
- db/da = 1 + 1 = 2 for b = a + a (one share per arrow)
- a.grad = e * b + d * 1 = (1)(3) + (-6)(1) = -3
- b.grad = e * a + d * 1 = (1)(-2) + (-6)(1) = -8
- slope check: ((3.001 + 3.001) - (3 + 3)) / 0.001 = 2

## Three key takeaways
- A node used k times receives k contributions, and they must be summed.
- Assigning with = overwrites earlier contributions, so only the last path survives.
- Because backward accumulates, gradients must be zeroed before each new step, and the same property enables gradient accumulation over small batches.

## Glossary
- Gradient accumulation: adding up the gradient contributions that arrive at the same node.
- Path: one route of arrows from the output back to a node; each path contributes one product.
- zero_grad: resetting every grad to 0 before the next backward pass.
- Overwrite: replacing a stored value instead of adding to it.

## Two common mistakes
- Using = in a backward rule: it looks fine until a node is used twice, then the gradient is silently too small.
- Forgetting to zero the grads between steps: the old gradients stay and the new ones are added on top.
