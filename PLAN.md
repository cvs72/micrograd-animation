# Animation plan: "How a neural network learns: backpropagation from zero" (after Andrej Karpathy's micrograd lecture)

Row format: `- [ ] ID | file | Class | min-max seconds | what the scene must show`
The builder ticks a row only after rendering it and checking frames; the loop un-ticks it if the reviewer fails it.
Rows must stay on ONE line each. Do not edit this file except to tick boxes.
CAPTIONS_REQUIRED: 8

## Audience and promise
A developer with no calculus background. After the video they can explain: what a derivative and a gradient are, what a computation graph is, how the backward pass applies the chain rule node by node, why gradients are added up (+=), and how gradient descent uses them to train a tiny network. Voice: a patient teacher, plain words, every new term defined the first time it appears. Target length 10 to 20 minutes in total.

## Global requirements (apply to EVERY scene; the reviewer checks them one by one)
G1 Subtitles. Every scene shows narration captions all the time, except on the title card and the recap line. Captions sit bottom-centre: white Text, font_size 30, on a semi-transparent black rectangle, at most 2 lines of about 12 words. Each caption stays on screen at least 2.5 seconds (about 0.35 s per word) and is swapped with FadeOut/FadeIn of about 0.3 s. Captions never cover the diagram. They say in plain language what is happening and why, as a teacher would say it aloud. The Narrator helper also writes every caption with start and end time to captions/<ID>.srt (overwritten on every render). verify.sh fails a scene that has fewer cues than CAPTIONS_REQUIRED.
G2 Never text only. Every scene contains at least two real visuals chosen from: Axes plot, node-and-arrow computation graph, 3D surface, code panel (Code mobject) with highlighted lines, bar chart, number line, table. Formulas and numbers support a visual and never replace it.
G3 Motion with meaning. Build every idea with Create, Transform or ReplacementTransform, Indicate, Circumscribe, ValueTracker with always_redraw, MoveAlongPath, FadeTransform or TransformMatchingShapes. At most two new elements appear per beat and each reveal is held at least 1 second. Show causes: when A changes B, animate the change travelling from A to B.
G4 One visual language across all scenes. Black background. White text. Data values BLUE. Gradients ORANGE. Forward-pass arrows and highlights TEAL. Backward-pass arrows and highlights ORANGE. The currently active element YELLOW. Secondary text GREY_B. A Value node always looks the same: a rounded rectangle with its name, data = x and grad = y, built by make_value_node. Shared helpers live in src/micrograd_animation/anim.py: palette constants, Narrator, make_value_node, arrow_between, title_card, recap_line, code_panel. S00 creates it. After S00 the file is append-only: add functions, never change the behaviour of existing ones.
G5 Honest numbers. Every number on screen comes from running the Value class in engine.py (or the nn.py classes built on it) inside the scene, with fixed random seeds and one number format (4 decimals, fewer when the value is exact). Assert in code the key results listed in each row, so a wrong number fails the render.
G6 Teaching rules. Each scene opens with a 3 second title card (chapter number and a one-line question) and ends with a 4 second recap line. One idea per beat. The first time a term appears (scalar, Value, child, computation graph, derivative, gradient, local derivative, chain rule, topological order, tanh, ReLU, loss, learning rate) show a short definition callout for at least 3 seconds. Each scene ends by raising the question that the next scene answers.
G7 Legibility. Safe margin 0.5 units. Minimum font size 24 (captions 30, node text 26). Nothing overlaps, nothing is clipped or off screen. Plot curves stay inside their axes and axes are labelled. Contrast must be readable at 480p.
G8 Quality bar before ticking a row. Render at -ql. Inspect at least 8 frames evenly spread over the scene (title card, one per beat, last frame) and confirm captions are present and readable in them. Duration inside the row's range. Record the 3 weakest points in progress.md. If any of G1 to G7 fails, fix it before ticking the row.
G9 Credit. S10 ends with the card: Based on Andrej Karpathy's micrograd lecture (Neural Networks: Zero to Hero). Explain everything in your own words and never copy his code text or visuals.

- [ ] S01 | scenes/scene01_derivative.py | Scene01Derivative | 60-120 | Chapter 1, what is a derivative? Function f(x)=3x^2-4x+5. Visuals: (1) Axes with labelled x and f(x), the curve drawn with Create; (2) a dot slides along the curve driven by a ValueTracker, with a tangent line that rotates and a live readout slope = 6x-4 whose value comes from Value.backward; the readout colour moves from ORANGE for negative slopes through WHITE at zero to TEAL for positive slopes; (3) a nudge section at x=1: the secant slope for h = 1, 0.1, 0.01, 0.001 shown in a table that fills row by row while the secant line rotates onto the tangent, converging to 2.0000; (4) a meaning beat: the sign of the slope says which way the function moves, and at the minimum x=2/3 the slope is zero (Circumscribe the point).
